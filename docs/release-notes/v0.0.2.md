# v0.0.2 更新说明

> 注：v0.0.2 发布时发布流水线还没有「更新说明」环节（本批新增），这份说明可手动粘贴到
> GitHub Release 页正文（Releases → v0.0.2 → 编辑）；从 v0.0.3 起自动注入，无需手工。

## 新增

- **运营面板**：项目内新增需求/审批/反馈与进度账本面板——主智能体维护进度条目，重大事项提请审批，worker 反馈闭环。
- **触发器分发器路由**：一个触发器事件可按话题聚类分发给多个订阅会话；新建触发器默认走分发器。
- **脚本触发器定时执行模式**：周期采集类脚本可按点执行（到点跑一趟即退出），不占常驻并发配额。
- **常驻脚本并发配额可配置**：设置 → 触发器中可调单项目与全局上限，改动约 5 秒生效。
- **引擎托管浏览器与登录闭环**：脚本可申请有头浏览器窗口完成登录，登录态加密存档并在无头执行时复用；登录失败自动暂停并唤醒订阅会话。
- **发布与自动更新体系**：tag 触发三平台（Windows/macOS/Linux）自动出包，应用内检查更新与强制升级守卫。

## 改进

- 主智能体锚定「项目总管」身份；worker（常驻执行智能体）编制与会话模型多轮真机打磨。
- 插件市场兼容上游 CDN 旧名清单；Python 运行时支持国内镜像加速下载。
