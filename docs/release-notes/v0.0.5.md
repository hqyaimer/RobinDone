# v0.0.5 更新说明

## 修复

- **修复从旧版本升级后无法完成启动准备的问题**（v0.0.4 独有）：在装有 v0.0.1–v0.0.3 历史数据的
  电脑上首次启动 v0.0.4 会在「正在更新任务索引」阶段卡住（诊断显示 sql_failed /
  0006_default_workspace_tasks）。原因是更名过程误改了一条历史迁移的匹配文本，本版本已还原，
  并兼容 v0.0.4 期间已建立的新数据。升级到本版本后原数据正常保留，无需任何手动操作。
- 若你的 v0.0.4 停在启动失败界面无法自动更新，请从 GitHub Releases 页手动下载本版本安装包覆盖安装。
